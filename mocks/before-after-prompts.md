# Making do / Just right: photo pairs for the homepage slider

**The idea:** the same room, the same camera, the same furniture, the same light. Only
the little things change. On the left they are the everyday make-do versions every Indian home
knows; on the right they are a matching, well-made set. The room itself is
already nice in both. What lifts it is the small stuff.

## How to make each pair (4 rooms = 8 images)

1. Run prompt **A (Just right)** in Gemini. Regenerate until you love it.
2. In the **same chat**, with that image attached, run prompt **B (Making do)**.
   It edits that exact frame, so nothing shifts when the slider is dragged.
   If Gemini moves the camera or changes the furniture, say: *"Keep everything
   identical to the image; only swap the objects listed."*
3. Download both at **16:9 landscape**. On a phone the slider shows the middle
   of the photo as a tall crop, so every swapped object must sit in the
   **centre half** of the frame. The prompts already ask for this.
4. Send me the 8 images; I'll name them, compress them and drop them in.

**Tone for every Making do photo:** clean, honest, ordinary, the way a real
family home looks. Never dirty, broken or mocked. Jugaad isn't wrong; it has
just been outgrown.
