Connect Cloudflare traffic

Web Analytics is already collecting on the live site. The dashboard needs three settings in Cloudflare to read it:

  1. Create an API token with only Account › Account Analytics › Read.
  2. In Pages → storeurbannest → Settings → Variables and secrets, add CF_API_TOKEN (as a secret), CF_ACCOUNT_ID and CF_SITE_TAG.
  3. Deploy. The token stays on the server; the browser never sees it.
