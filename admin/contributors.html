How their login works
  1. Add them above. Urban Nest emails them an invite straight away.
  2. They tap the link in the email and choose their own password. You never see it.
  3. From then on they sign in at storeurbannest.in/studio/. The Login column above shows whether they've done it.

Invite expired, or they can't find the email? Press Send login email on their row. Supabase sends only a few emails an hour, so if it says to wait, try again later.

If the button ever doesn't work

Send it by hand: Supabase → Authentication → Users → Add user → Send invitation, with the same email.
